# OQ-contribution-license: Under what license is contributed content offered?

- **ID:** OQ-contribution-license
- **Status:** open

## Question

Which license applies to what people contribute (problems, options, evidence summaries, archive records), so others may reuse it?

## Why it matters

The Archive only helps if paths can be reused. Attribution keeps reuse traceable: a community that adopts a path can follow it back to where it was proven, and the source is credited.

## Current default (what we built meanwhile)

CC BY 4.0 for contributed content, which requires attribution. The alternative is CC0 (no conditions). Code stays MIT (D-49).

## Who can help

Open-licensing and open-data lawyers; civic-tech maintainers; archivists.

## What a good answer looks like

A recommendation between CC BY 4.0 and CC0 with the effect on attribution, jurisdictions with moral rights, and what the attribution line must contain.

# OQ-help-needed-tags: How strictly is help_needed checked?

- **ID:** OQ-help-needed-tags
- **Status:** open

## Question

Each public problem carries a `help_needed` set (skill groups, languages, coarse place, topic). How strictly must volunteer review check it?

## Why it matters

Wrong tags send the wrong people to a problem or hide it from the right ones. Strict checking slows publication and adds a burden for reviewers.

## Current default (what we built meanwhile)

The poster proposes the set during preparation, volunteer review checks it, and the publication run validates the tag set against the taxonomy. Review may correct tags but a wrong tag alone does not block publication.

## Who can help

Volunteer reviewers, community organisers, moderators, and people who have tried to find help for a public problem.

## What a good answer looks like

A short checking rule, a measure of how often tags are wrong in practice, and whether wrong tags should ever block publication.

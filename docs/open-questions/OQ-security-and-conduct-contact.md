# OQ-security-and-conduct-contact: Where do security and conduct reports go?

- **ID:** OQ-security-and-conduct-contact
- **Status:** open

## Question

How can someone privately report a security vulnerability or a conduct problem before the project has a hosted repository and a named team?

## Why it matters

A public issue tracker is the wrong place for a vulnerability or a harassment report. Without a private channel, people either stay silent or disclose in public.

## Current default (what we built meanwhile)

No private channel exists yet. Until the repository is hosted, reports go privately to the founder through whatever channel they used to share the repository. GitHub private vulnerability reporting is enabled at hosting time, and `SECURITY.md` and `CODE_OF_CONDUCT.md` then name the channel.

## Who can help

Security engineers who have run coordinated disclosure; governance and community-conduct practitioners.

## What a good answer looks like

A short procedure: the channel for each report type, who reads it, the response times, what happens when the reader is the subject of the report, and how reporters are protected.

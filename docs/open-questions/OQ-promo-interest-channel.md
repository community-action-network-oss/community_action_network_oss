# OQ-promo-interest-channel: How can a visitor register interest without handing over personal data?

- **ID:** OQ-promo-interest-channel
- **Status:** open

## Question

What channel, if any, should the gallery offer for people who want updates or want to help?

## Why it matters

A form or list collects personal data and needs a controller, storage and a privacy notice. A repository link needs none.

## Current default (what we built meanwhile)

No form, no list, no analytics. The primary call to action is the repository and its open questions. The repository link points at the GitHub organization `community-action-network-oss`. GitHub Discussions is a candidate interest channel; the decision stays with the founder.

## Who can help

Privacy engineers; community managers; open-source maintainers who have run public discussion spaces.

## What a good answer looks like

A recommendation among repository discussions, a mailing list, or a privacy-minimal form, with the data held, retention and who operates it.

# OQ-native-device-testing: Who can test native-only behaviour on real devices?

- **ID:** OQ-native-device-testing
- **Status:** open

## Question

Which volunteers can test secure storage, push notifications, deep links and screen readers on real iOS and Android devices?

## Why it matters

Slice 1 is verified on web only. Native-only behaviour is untested until people with devices help.

## Current default (what we built meanwhile)

Web verification only. Native builds must bundle. Device tests are founder-gated.

## Who can help

iOS and Android testers; assistive-technology users; mobile engineers.

## What a good answer looks like

A volunteer test plan for one flow on 2 devices per platform, with a checklist and a way to report results.

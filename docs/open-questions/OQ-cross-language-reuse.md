# OQ-cross-language-reuse: How does reuse work across languages?

- **ID:** OQ-cross-language-reuse
- **Status:** open

## Question

How should a problem in one language find and show archived paths written in another?

## Why it matters

A path proven in one country is most valuable to a place that speaks a different language.

## Current default (what we built meanwhile)

Shared multilingual embeddings are used for retrieval, and translation is used for display, labelled as machine translated. The structured `context_profile` is language independent.

## Who can help

Multilingual NLP researchers; translators; localization specialists.

## What a good answer looks like

An evaluation of retrieval quality across the launch languages and a rule for labelling translated content.

# OQ-eligible-categories: Which kinds of public problem are eligible, and which are excluded?

- **ID:** OQ-eligible-categories
- **Status:** open

## Question

What is the real list of eligible problem categories and explicit exclusions for the pilot?

## Why it matters

It decides what the moderation run accepts, what users see in the form, and which problems are redirected. A list that is too broad invites conflict; too narrow fails people.

## Current default (what we built meanwhile)

A placeholder list for the seed problems (synthetic evidence): public services, infrastructure, environment, safety, accessibility. Exclusions follow the scope rule (no individual advice, no emergencies, no named private people).

## Who can help

Policy analysts; civic practitioners; policy labelers; journalists.

## What a good answer looks like

A category list of 5 to 10 entries, each with an example, a counter-example and the routing for near-misses.

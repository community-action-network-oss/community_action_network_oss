# OQ-handle-scope: One handle per account, or a different pseudonym per problem?

- **ID:** OQ-handle-scope
- **Status:** open

## Question

Should a person keep one public handle everywhere, or get a separate pseudonym per problem?

## Why it matters

One handle builds a recognizable history but can link someone across problems. Per-problem handles protect privacy but hinder trust and abuse handling.

## Current default (what we built meanwhile)

One generated handle per account, with one regenerate before first publish.

## Who can help

Privacy researchers; trust-and-safety practitioners.

## What a good answer looks like

A comparison of the two with the abuse and privacy trade-offs and a recommendation.

# OQ-edit-after-publication: How can published text be edited without hiding history?

- **ID:** OQ-edit-after-publication
- **Status:** open

## Question

What can an author change after publication, what needs a visible correction, and what history is kept?

## Why it matters

Honest correction matters, and so does the right to remove personal information quickly.

## Current default (what we built meanwhile)

Published text is not edited. An author can add a visible correction note or tombstone their own text. Moderators can hide text with a decision. Originals stay in history unless personal data must be removed.

## Who can help

Archivists; editors; privacy specialists.

## What a good answer looks like

A rule set for edit, correct, hide and remove, with examples.

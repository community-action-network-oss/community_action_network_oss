# OQ-guest-read-search-indexing: Can guests read problems, and may search engines index them?

- **ID:** OQ-guest-read-search-indexing
- **Status:** open

## Question

Should unauthenticated visitors read published problems, and should those pages appear in web search?

## Why it matters

Indexing makes a mistake permanent in practice. Blocking it limits discovery and trust.

## Current default (what we built meanwhile)

Guests can read published problems. All pages are `noindex` in slice 1.

## Who can help

Privacy engineers; journalists; SEO and web-archive specialists.

## What a good answer looks like

A recommendation with rules for when indexing could start (for example per jurisdiction and after removal tooling exists).

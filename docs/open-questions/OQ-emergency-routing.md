# OQ-emergency-routing: Which emergency and crisis resources are shown, per jurisdiction?

- **ID:** OQ-emergency-routing
- **Status:** open

## Question

For each launch jurisdiction, which static emergency and crisis routes should every form show, who verifies them and how often?

## Why it matters

The platform is not an emergency service. A wrong or stale number can cause harm. This is a hard blocker for publishing anything real.

## Current default (what we built meanwhile)

Every form shows a generic "If someone is in danger, contact your local emergency number" notice. No real numbers. The Amsterdam (NL) overlay uses placeholder text until real, reviewed resources exist (`OQ-amsterdam-overlay-review`).

## Who can help

Crisis-service professionals; public-safety workers; translators; accessibility reviewers.

## What a good answer looks like

A verified list for one named jurisdiction with sources, a named review owner and a review date.

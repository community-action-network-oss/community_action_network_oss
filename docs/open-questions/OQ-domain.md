# OQ-domain: What public name and domain should the project use?

- **ID:** OQ-domain
- **Status:** open

## Question

What brand name, domain name and visual identity should the project use publicly?

## Why it matters

The domain appears in emails, links and the gallery, and is hard to move later. The name needs a trademark and clash check.

## Current default (what we built meanwhile)

No domain and no brand. The code is hosted on GitHub under the organization `community-action-network-oss` (repository hosting is answered; the domain and brand are still open). The gallery links to those repositories. Local development uses localhost ports.

## Who can help

Naming and brand designers; trademark searchers; nonprofit counsel; accessibility-minded visual designers.

## What a good answer looks like

A short list of 3 to 5 names with domain availability, trademark search notes in at least two regions, and pronounceability and translation checks.

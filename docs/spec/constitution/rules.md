# Rule registry

Machine-testable rules that bind slice 1. Shape: `RULE-ID | source | trigger | must / must-not | evidence | test | first phase`. Source IDs are the new chapter IDs (see `map.tsv` for old article numbers). A rule changes only through the amendment or policy-pack process (V.5, VIII.2); rules move into the `can_policy` repository over time. The legal layer and simulation rules live in [`rules-legal-sim.md`](rules-legal-sim.md) (split to stay under 25KB). `tools/check.mjs` fails if a rule ID used in a chapter is missing from both files, or the reverse.

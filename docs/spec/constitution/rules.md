# Rule registry

Machine-testable rules that bind slice 1. Shape: `RULE-ID | source | trigger | must / must-not | evidence | test | first phase`. Source IDs are the new chapter IDs (see `map.tsv` for old article numbers). A rule changes only through the amendment or policy-pack process (VIII.2). `tools/check.mjs` fails if a rule ID used in a chapter is missing here, or the reverse.
